# Page 3 probe, take 1 -- Car Settings (TC/ABS/BrakeBias/EngineMap/OilTemp).
# Protocol doc says slot 0x85, handle range 0-5 + 13, no suffix.
# Hypothesis: positions 0-3 -> handles 2-5 (matching Page 4's slot 0x88
# pattern), position 4 -> handle 13 (the "extra" handle in the doc range).
# SPEED/GEAR header at handles 0/1 as usual (kick required).
#
# *** SAFETY WARNING ***
# Doc notes BRAKE_BIAS (paramId 25, f32) values >= 127 crash PBME firmware,
# and rapid value cycling on Page 3 can cause lockups. Keep BB well under
# 127 (56.0 used here) and space all changes out with generous sleeps.
#
# Run with: script scripts\page3-probe1.txt
#
# Step 1: activate, pageset Page 3, paramdefs, kick + settle, send baseline.
#         Note which fields render and where (TC=3, ABS=5, BB=56.0,
#         EngMap=2, OilTemp=80 -- distinctive values to spot each one).
# Steps 2-6: change each field individually to confirm the mapping.

connect
activate on

pageset 3 3
paramdefs 85 00 00 - 85 01 00 - 85 02 00 - 85 03 00 - 85 04 00 -
keepalive
sleep 200
value 0 1 i16 55
value 1 4 u8 3
value 2 20 u8 3
value 3 18 u8 5
value 4 25 f32 56.0
value 5 26 u8 2
value 13 33 u8 80
sleep 5000

# --- Step 2: TC 3 -> 8 ---
value 2 20 u8 8
sleep 4000

# --- Step 3: TC back, ABS 5 -> 9 ---
value 2 20 u8 3
value 3 18 u8 9
sleep 4000

# --- Step 4: ABS back, BB 56.0 -> 57.0 (small delta, well under 127) ---
value 3 18 u8 5
value 4 25 f32 57.0
sleep 4000

# --- Step 5: BB back, EngineMap 2 -> 5 ---
value 4 25 f32 56.0
value 5 26 u8 5
sleep 4000

# --- Step 6: EngineMap back, OilTemp 80 -> 95 ---
value 5 26 u8 2
value 13 33 u8 95
sleep 4000
